# Release readiness — 2026-08-12

This is the evidence ledger for the first TestFlight candidate. It records what passed locally
and leaves external or physical-device gates open rather than treating them as implied passes.

## Passed locally

- Server lint passed.
- Database suite passed: 558 assertions across 19 pgTAP files, including configurable pilot
  cohort enrollment and its capacity/rollover checks.
- Edge Function suite passed: 216 tests.
- `npm run audit:leak` passed all four suites. The 105-sample submitter-count timing run measured
  Pearson `r = -0.1426`, inside the required `|r| < 0.2` bound. Golden coverage, response-length
  invariance, group-blind rate limits, locked PostgREST tables, anonymous function rejection,
  cross-group isolation, ex-member rejection, DTO field scanning, and the `joined_at` omission all
  passed in that run.
- iOS source/copy/security lint passed, including the no-secret-field, no raw `Date()`, no banned
  copy, no inline feature copy, and design-token checks.
- Current runtime (iOS 26.5, iPhone 17 Pro simulator): all 371 unit tests in 43 suites passed.
- The 53-test, 9-suite snapshot matrix passed apart from the two expected one-hour plural changes;
  those `SE` and `15 Pro Max` accessibility-5 goldens were inspected, updated from “1 hours” to
  “1 hour,” and the complete `SubmitSnapshots` suite then passed.
- `Localizable.stringsdict` is valid. Focused plural tests pass for one/many hours, minutes, songs,
  export omissions, and the two-count share headline.
- `FullLoopUITests` drives submit → seal → reveal → seven guesses → results in 12 taps. Standard
  and reduced-motion ledgers measured 7.66s and 6.92s of interaction time respectively, both
  below 90s. The suite also covers a foreign timezone/future device context and walks visible
  actionable accessibility elements for empty labels across search, confirm, sealed, reveal,
  results, and The Record.
- The focused renderer and debounced-guess regressions pass after making their suite-load timing
  guards deterministic.
- An unsigned Release simulator build passed. A string scan found none of
  `SPOTIFY_CLIENT_SECRET`, service-role markers, private-key headers, the fixture bearer, or the
  fixture-session/reduced-motion launch arguments. The same scan must still run on the signed IPA.
- Hosted Supabase project `blind-drop` (`ojzwgaffeegssfscoaiv`, `us-west-1`) is active. All
  migrations and seven Edge Functions are deployed; the hosted anonymous-envelope smoke test
  passed. The public project URL/publishable key are wired into the Release configuration.
- The initial TestFlight cohort is enabled with capacity 12 and code-free enrollment. Additional
  cohorts can be added and ordered in `pilot_cohorts` without shipping another app build.
- A durable `demo@blinddrop.dev` password account is provisioned for App Review in its own
  cohort. It cannot see pilot data or consume one of the 12 tester seats.
